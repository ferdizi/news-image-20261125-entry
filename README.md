One image that sums up 25 November 2026's world news: 38 verified stories from 10 regions, drawn as 13 scenes around a masthead, a stat strip, a timeline, three hero stories and a region map. Every claim on the image is labelled with its source, and the image is rendered deterministically at 1024×1024 so the same input always produces the same picture.

## How to run

Run the entrypoint to regenerate the image:

```sh
node main.ts
```

It copies `entry.png` into `output/entry.png` (or into `$MAKEFUN_OUTPUT_DIR` when that is set).
